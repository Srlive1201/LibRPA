# IBZ-only SOC native head/wing regression

This finite software model has one atom, two spatial s NAOs, four spinor
bands, two occupied states, a positive nonorthogonal overlap, interorbital
SOC and nontrivial unitary gauges within exact Kramers pairs. It tests the
ordinary G0W0 driver; it is not a material or a convergence benchmark.

The full mesh is `(0, +1/3, -1/3)` along the first reciprocal direction.
The input contains only `(0, +1/3)`, with star multiplicities `(1, 2)`;
time reversal reconstructs the third point. Native preset 6 computes source
velocities from the retained H/S/r matrices in the supplied SCF frame.
There is no velocity file, full-grid wavefunction cache or separate PyATB
snapshot in `dataset.tar.gz`. Both analytic head and wing are nonzero.

The ordinary body reader divides raw occupations by the active point count.
Thus the two occupied states have raw `band_out` occupations `2/3` at Gamma
and `4/3` at `+1/3`, giving `wg_i = (m_i/3) f_i` with physical `f_i = 1`.
Only the owned head/wing copy is converted to `f_i/N_IBZ`; the original body
weights must remain unchanged. Unequal stars make this distinction visible.

## Independent reference

The active numerical reference comes from an independent, explicitly supplied
three-point, symmetry-OFF native run with the same retained full-input bundle.
The full-grid C was independently diagonalized, rather than restored from IBZ.
Both magnetic/IBZ and full-grid native Sigma agree within 1.0e-17 Ha.

The complex charge bubble now supplies the negative-time factor with the AO,
translation and spin adjoint required by the charge trace. Swapping spin labels
alone is insufficient for complex spinors. The corrected response was checked
independently against the original-KS Lindhard sum

`P_mu,nu(q,iw) = (1/Nk) sum_knm (f_kn-f_k+q,m)/(iw+E_kn-E_k+q,m)`
`                 * V_mu(kn,k+q,m) * conj(V_nu(kn,k+q,m))`.

For this one-center model, `V_mu = C_kn^dagger (Cs_mu+Cs_mu^T) C_k+q,m`, with
both spinor components retained. At every one of the three q points and six
original frequencies, the maximum error across 162 complex response entries is
6.23e-11. The existing `test_crpa_soc` also checks the complex charge response
against independent spectral sums. The old pre-adjoint Sigma differs by
1.42e-4 Ha and is not used as the corrected target.

The corrected full-grid reference includes both charge-vertex and negative-time
Green-function corrections. The H/S/r, eigenpairs, occupations, frequency nodes
and existing tolerances are retained. Historical pre-correction outputs remain
in the preserved development workspace and are not regression targets.

The H/S/r and eigenvectors retain their independent Fourier-derivative and
magnetic-sewing checks from the original fixture.

The reference directory retains the full stdout content as `librpa/librpa.out`,
complete head/wing CSV, and all 12 complete 4x4 Sigma matrices at the two
common representatives and six original imaginary frequencies. The QP table
contains all four states at all three full-grid points. These references
were not generated by the IBZ candidate. `runtime_route.txt` separately lists
required candidate flags and actual head/wing restoration messages.

The small `refs/.../full-input/` bundle retains the full-reference input:
unpack its `dataset.tar.gz` into a fresh directory, place its `librpa.in` in
a sibling `librpa/` directory, and run the driver from that directory with
one MPI rank and `OMP_NUM_THREADS=1`. It is provenance for the golden data,
not a second registered case. Do not replace golden outputs with the IBZ run.

## Existing-framework checks

One `testsuite.xml` entry uses existing comparators for:

- Native velocity, spinor input, two source points and active head/wing
  reconstruction at runtime.
- All 54 complex Cartesian head entries and 54 complex auxiliary-wing
  entries, including frequency and matrix indices, to `1e-10` in native units.
- All 192 complex Sigma entries at the common representatives, to `1e-10 Ha`.
  The existing binary extractor also compares the two matrix-header integers.
- Every printed occupation and every EXX/Sigma/QP table entry, to `1e-4`
  (energies in eV; printed energy resolution is `1e-5 eV`).

The standard LibRI suite runs this case on four MPI ranks; it also supports
the normal `--only g0w0_soc_ibz_headwing_libri -n 1` invocation. No special
runner, comparison module or reference-update script is needed.
